# API для Yatube

REST API для социальной сети **Yatube** — блог-платформы, где пользователи могут публиковать посты, оставлять комментарии, подписываться друг на друга и объединяться в сообщества.

Проект выполнен в рамках финального спринта курса «Django REST Framework» на **Яндекс Практикуме**.

## Основные возможности

- Получение, создание, обновление и удаление публикаций
- Добавление и управление комментариями к постам
- Просмотр списка сообществ
- Подписки на других пользователей
- Аутентификация через JWT-токены

## Технологии

- Python 3
- Django 3.2
- Django REST Framework
- djangorestframework-simplejwt
- SQLite
